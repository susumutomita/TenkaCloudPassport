# App Store 申請の現状

会話 AI は廃止済み。旧 1.2.0 の Apple Intelligence 説明、会話画面の審査手順・スクリーンショットは現在の申請に使用しない。

現在の機能は自己紹介カード・QR と外部教材のオフライン学習。学習記録には自己評価が含まれ、コード実行・検証や合格を保証しない。教材の取得には通信が必要。旧モデルファイルの容量確認と、確認付きの旧モデルだけの削除は設定から行う。

申請前に対象版・コミット・ビルド番号を固定し、現在の説明と iPhone / iPad の画面を準備する。実機の起動・IME・ソフトウェアキーボード・旧モデル削除・ネイティブ学習保存は確認が必要。

ASC の既存サポート・プライバシー URL、プライバシー・年齢・輸出規制の申告は実際の設定を確認する。未知の回答や契約同意を推測で更新しない。

既存 EAS 経路は TestFlight アップロードであり、Apple の処理完了・App Store 審査提出・公開は別の段階として記録する。旧メタデータは Git の過去版に保持する。
